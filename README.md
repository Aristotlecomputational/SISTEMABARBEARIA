# SISTEMABARBEARIA
DUPLA: SELSO ALEXANDRE DE OLIVEIRA SOARES FILHO E LUAN AZEVEDO BELTRÃO

NO CÓDIGO DO SISTEMA DA BARBEARIA, UTILIZAMOS COMO LÓGICA DIVERSAS COISAS, DENTRE ELAS O EMPREGO DE DICIONÁRIOS, LISTAS, FUNÇÕES PARA REUTILIZAÇÃO E LIMPEZA DE CÓDIGO BEM COMO TRATAMENTO DE ERROS E LOOPS PARA O DEVIDO FUNCIONAMENTO DO SISTEMA DE BARBEARIA. NAS PRIMEIRAS LINHAS, DEFINIMOS O PREÇO DOS NOSSOS SERVIÇOS, CRIAMOS AS LISTAS VAZIAS DE ESPERA, CLIENTES ATENDIDOS E ESTATÍSTICAS. POSTERIORMENTE, FIZEMOS UMA VERIFICAÇÃO PARA QUE A ENTRADA DO USUÁRIO NÃO QUEBRE O CÓDIGO; DEPOIS UM WHILE TRUE GERAL PARA O CONTROLE DE FLUXO, UM MENU COM VÁRIOS PRINTS E UM PEQUENO TRATAMENTO DE ERRO USAMDO TRY E EXCEPT. MAIS ADIANTE, FIZEMOS, PARA CADA NÚMERO DIGITADO, UMA OPÇÃO QUE FARÁ AQUILO QUE FOR PEDIDO, COMO A CIRAÇÃO DE UM CLIENTE VIA OBJETO, COM AS RESPECTIVAS CARACTERÍSTICAS, OUTRA FUNÇÃO PARA ADICIONAR A QUANTIDADE DE SERVIÇOS ESPECIFICADOS REALIZADOS, E NO FINAL ADICIONAMOS O CLIENTE À LISTA VAZIA DE ESPERA. NA OPÇÃO 2 FIZEMOS UMA VERIFICAÇÃO PARA VER SE A LISTA ESTAVA VAZIA, UM FOR PARA ITERAÇÃO DENTRO DA FILA DE ESPERA JUNTO AOS SERVIÇOS. NA OPÇÃO 3, A REALIZAÇÃO DO ATENDIMENTO, COM UMA VERIFICAÇÃO PADRÃO DE LISTA VAZIA E ABAIXO UMA ADICÃO CONDICIONAL DOS SERVIÇOS, SEGUIDA DO PRINT DAS INFORMAÇÕES DO USUÁRIO JUNTO ÀS ESTATÍSTICAS SENDO ADICIONADAS (OU NÃO) DE ACORDO COM UMA CONDICIONAL "IF". POR FIM, O RELATÓRIO DE GESTÃO COM O TOTAL DE CLIENTE ATENDIDOS, E UM PRINT GERAL DO FATURAMENTO, SERVIÇO, DADOS UNITÁRIOS ETC. UMA SOMA IMPORTANTE DO FATURAMENTO TOTAL E UMA ÚLTIMA OPÇÃO PARA SAIR DO PROGRAMA CASO O NÚMERO DIGITADO SEJA 0 E UM ELSE PARA FORÇAR O USUÁRIO A DIGITAR CORRETAMENTE.
